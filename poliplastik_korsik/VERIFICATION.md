## API и отсутствие LLM

С загруженными настоящими моделями и реальным Qdrant проверены FastAPI endpoints
через TestClient: readiness, отказ неавторизованному запросу, разбор контекста
сотрудника и `POST /rag/ask`. Endpoint без LLM вернул:

```json
{"status":"service_error","error_code":"llm_not_configured","sources":[]}
```

Это реальная проверка отсутствия конфигурации, **не проверка генерации**.
LLM endpoint/model/key не предоставлены. Ни один ответ настоящей LLM не генерировался.
HTTP-протокол ошибок/тайм-аута проверен с MockTransport, не с живым сервером LLM.

## Небольшие проверки контрактов

9 тестов RAG прошли: совместимость с canonical OCR snapshot и смещениями,
переиспользование/атомарность обновления, рассогласование индексов, фильтрация
доступа до reranker/контекста, подготовка BM25, продолжение условий между
страницами, поддельные цитаты/неполные связанные источники, различие timeout и
отсутствия ответа, сервисная авторизация API.

В этих 9 тестах используются искусственные векторы и Qdrant local-memory,
кроме отдельно описанного полного прогона с реальными моделями и сервером.
Смоделированное LLM-сообщение проверяет только формат/ссылки/маршрут статуса,
а не способность модели отвечать на вопросы. Проверен отказ при превышении
лимита токенов до inference, без усечения.

20 прежних проверок OCR прошли. Основные исходные файлы OCR (`ingest.py`,
`ocr_core.py`, `extract.py`, `chunks.py`, `review.py`, `policy.json`,
`validate_corpus.py`) побайтово совпадают с предоставленным актуальным ZIP.
Тесты не запускаются при обычных вопросах сотрудников.

## Практические границы

- Персональная применимость зависит от доверенного backend-контекста и явной
  аннотации организации. Неизвестные новые документы нельзя молча открыть всем.
- Корпус ограничен извлечёнными основными текстами. Дополнительные скриншоты,
  отсутствующие приложения и расписания не восстанавливаются из догадок.
- Контекст расширяется целыми разделами и может включать близкие, но ненужные
  фрагменты. Лимит не достигается обрезанием исключений; если основное правило
  не помещается, возвращается ошибка бюджета. Для LLM настрой её реальный
  токенизатор и контекстное окно; консервативная оценка по байтам строже.
- Проверка JSON/дословных цитат подтверждает происхождение источников. Она не
  доказывает логически каждый вывод LLM. Правильность итоговых ответов, особенно
  отрицательных, условий подарков и персонального графика, требует живого прогона.
- Windows-команды подготовлены, OCR ранее проверен пользователем на Windows.
  Сам новый RAG прогонялся в Linux. MAX-бот, БД сотрудников и HR-действия в этом
  архиве отсутствуют; сервис подключается к ним через Python/API.
