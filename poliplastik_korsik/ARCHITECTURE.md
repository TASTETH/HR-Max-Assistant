# Точка подключения и решения

`ingest.load_current(output, require_ready=True)` проверяет завершённый снимок.
RAG дополнительно проверяет chunk_id, смещения текста и привязку к сегментам.
Корневые копии JSONL не используются для индексации. Готовый chunking сохранён.

| Слой | Решение и причина |
|---|---|
| Dense | BGE-M3 через sentence-transformers; нормализация, cosine, revision pinned |
| Векторы | Qdrant 1.15.4, постоянный Docker volume; UUID5 от chunk_id, SHA-ID в payload |
| Лексика | BM25Okapi в RAM на активный корпус; ё→е, русский Snowball, без удаления отрицаний/контактов/номеров |
| Fusion | RRF k=60: объединяет позиции, а не несопоставимые значения разных score |
| Reranker | CrossEncoder BGE-reranker-v2-m3; 12 кандидатов, сырые logits |
| Контекст | Слияние перекрытий, целые разделы, продолжение между страницами и одноимёнными слайдами, источники добавленного текста |
| Доступ | Одинаковый allowed set для BM25 и Qdrant; расширение контекста тоже проверяет документ |
| Ответ | Один OpenAI-compatible chat request, JSON, цитаты только из переданных источников |
| API | FastAPI, один worker, один compute slot, threadpool для inference |

Ревизия индекса содержит embedding model/revision, настройки dense, версию
подготовки BM25, коллекцию, количество чанков и fingerprint корпуса. Снимок
содержит chunks, segments и scope с контрольными суммами. Перед активацией
проверяются фактические ID/количество/метки корпуса Qdrant. BM25 строится один раз
из того же файла chunks. Частичная коллекция не активируется. Перезапуск API
переключает процесс на успешно построенную новую версию.

Права и организацию задаёт доверенный backend. Вопрос и история их не меняют.
Поиск берёт список разрешённых UUID до dense retrieval и маску тех же chunk_id
до отбора BM25. В reranker и LLM попадают только разрешённые результаты.

Расширенные источники сохраняют исходные segment_id, source_sha256, страницу,
смещения и связанные chunk_id. Превышение длины входа embeddings/reranker вызывает
явную ошибку; вход не обрезается. Общий контекст ограничен отдельно. Дословная
цитата LLM сопоставляется переданному диапазону источника; чужой ID/цитата либо
answered без источников превращается в service_error, без повторной генерации.

PostgreSQL, Redis/Celery и HR-интеграция остаются в основном приложении.
Новых хранилищ, frontend, очередей или агентных циклов здесь нет.
