# Исправление формирования цитат в RAG Корсика

Повод: на вопрос «Можно ли принимать денежные подарки?» модель предложила
ответ, но проверка вернула `quote_not_found`. Пользователь получил обещание
уточнить вопрос вместо автоматического ответа.

## Изменение

Фрагменты размечаются метками предложений S1, S2, ... внутри F1, F2, ... .
Модель выбирает `fragment` и `sentence_ids`, а сервер извлекает точные выдержки
по позициям в исходном тексте. Модель больше не переписывает цитаты вручную.
Схема JSON и инструкции обновлены одновременно. Выдуманный фрагмент,
выдуманная метка, пустое доказательство и отсутствие claims отклоняются.
Существующая проверка чисел сохранена. Метки и заголовки учитываются при
проверке бюджета контекста. Сохраняются только целые фрагменты.

`llm.py` сохраняет предыдущую настройку `think=False` для Qwen.
Модель, поиск, история диалога, база, сценарий, MAX и очереди не меняются.
Извлечение точной цитаты не доказывает смысловую корректность ответа:
проверка полноты условий и качества рассуждения остаётся необходимой.

## Установка на Windows

1. Сохраните копии текущих `backend/korsik/rag/answer.py` и `backend/korsik/llm.py`.
2. Скопируйте папки `backend` и `seed` из архива в `korsik_v2` с заменой файлов.
   Не создавайте дополнительную вложенную папку проекта.
3. Из PowerShell в папке `korsik_v2`:

```powershell
docker compose up -d --build app worker
docker compose exec worker python -m korsik.cli ask "Можно ли принимать денежные подарки?"
```

4. Повторите тот же вопрос новым сообщением в MAX. Ожидается `answered`
   с источником «Антикоррупционная политика», слайд 9. В диагностике нового
   запроса будет `evidence_mode=sentence_ids_v1` и серверные выдержки.
5. Если диалог взят HR в работу, сначала верните его Корсику.
   Режим «Ждёт HR» сам по себе не блокирует новые автоматические ответы.
   Старые обращения этим обновлением не закрываются.

`.env`, сертификаты, pgdata и данные сотрудника сохраняются.
Не удаляйте контейнерные тома. Окно Cloudflare-туннеля оставьте открытым.

## Проверки

Выполнены 17 локальных тестов реального модуля `answer.py` с заменой внешних
границ (поиск, настройки и вызов Ollama). Они проверяют извлечение точных
выдержек, сохранение исходного текста, отказ на неизвестные метки и фрагменты,
ссылки для каждого claim, числа, отказ модели, уточнение, ошибки сервиса,
историю и бюджет контекста. Тесты не используют сеть и не отправляют сообщения:

```powershell
docker compose exec app python /app/seed/rag_eval/test_sentence_evidence.py
```

Реальная генерация Qwen и доставка MAX в этой среде недоступны: их необходимо
повторно проверить на запущенном компьютере. Архив не является результатом
повторного прогона выборки из 65 вопросов. После проверки единичного отказа
можно запустить прежний evaluator заново: формат sentence_ids меняет контракт
доказательств, поэтому метрики предыдущего прогона не переносятся автоматически.

Ответы про VPN и личные задачи требуют своих инструкций и получения
персонального плана при ответе. Это исправление не добавляет таких материалов.
